# 📊 Machine Learning Projects – Insurance & Heart Disease Analysis

Welcome to my Machine Learning projects repository! This repository contains two practical data analysis projects where I explore real-world datasets, perform data cleaning, preprocessing, Exploratory Data Analysis (EDA), and statistical analysis using Python.

These projects are part of my journey toward becoming a Machine Learning / AI Engineer.

---

## 📁 Projects Included

### 1. 🏥 Insurance Cost Analysis

**Objective:** Analyze the factors that influence medical insurance charges and understand the relationship between different customer attributes and insurance costs.

**Key Work:**
- Data loading and inspection using Pandas.
- Data cleaning and preprocessing.
- Handling categorical variables using One-Hot Encoding.
- BMI category creation and feature engineering.
- Exploratory Data Analysis (EDA).
- Data visualization using Matplotlib and Seaborn.
- Statistical feature analysis using the Chi-Square test.
- Dividing insurance charges into quartiles for statistical analysis.

**Dataset Features:**
- Age
- BMI
- Children
- Gender
- Smoking Status
- Region
- Insurance Charges

**Libraries Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn

---

### 2. ❤️ Heart Disease Data Analysis

**Objective:** Explore a heart disease dataset to understand the relationship between patient health characteristics and the presence of heart disease.

**Key Work:**
- Dataset loading and inspection.
- Data cleaning and preprocessing.
- Handling invalid zero values in Cholesterol and Resting Blood Pressure.
- Replacing invalid values using column means.
- Handling duplicate and missing values.
- Exploratory Data Analysis (EDA).
- Univariate and bivariate analysis.
- Data visualization using Matplotlib and Seaborn.
- Correlation analysis.
- Outlier detection and analysis.

**Dataset Features:**
- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Maximum Heart Rate
- Heart Disease

**Libraries Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🚀 How to Run These Projects

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd Machine-Learning-Projects
```

**3. Install the required libraries**

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

**5. Open the notebook you want to explore.**
